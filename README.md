# Слои карты в приложении — прототип

Отдельный статический прототип: `index.html` без сборки. Квартиры с фото, районы и контуры районов взяты из прототипа «Транспортная доступность» (`js/data.js`, `js/districts.js`, `js/districts-zones.js`, `photos/`).

Чтобы открыть на телефоне: Settings → Pages → Deploy from a branch → `main` / root.

Экраны (ссылки):
- `#rent-layers` — слои под запрос, аренда
- `#rent-districts` — слои включены → подборка квартир и районов
- `#rent-myday` — мой день на карте
- `#buy-layers` — слои под запрос, покупка
- `#buy-story` — район на вырост
- `#rent`, `#buy` — свободный режим

На телефоне меню экранов — тройной тап.

Карта — живая карта Яндекса с контурами районов из OpenStreetMap. Фото квартир — из прототипа, фото районов, парков, школ — Викисклад. Признаки районов для слоёв выведены из полей районов, цены покупки и платежи — пример для концепта.
